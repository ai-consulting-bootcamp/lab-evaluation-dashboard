# Reflection

I built the dashboard around three questions a stakeholder can answer quickly. Which categories score highest on average? How much do scores vary within each category? Where do scores cluster overall? The ranked bars answer the first question, and the box plots and histogram add context about the spread. Filters let stakeholders explore the same questions for a particular model, category, or time period.

For a future version, I would agree on a minimum acceptable score with stakeholders and add the share of evaluations below that threshold. I would also show the number of evaluations in each filtered view so that stakeholders can judge how much data supports a comparison.
