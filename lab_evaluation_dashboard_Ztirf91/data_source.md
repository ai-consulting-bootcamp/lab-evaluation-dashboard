# Data source

This Tableau Public dashboard uses 4,489 synthetic evaluation records generated with the lab's Python script (`generate_evaluation_data.py`, random seed 42). The sample data was chosen to demonstrate how to compare score distributions across evaluation categories and model versions. The included CSV covers 26 August through 23 November 2026 and contains evaluation IDs, categories, scores from 0 to 100, model versions, and dates.
