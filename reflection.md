# Lab Reflection — Evaluation Dashboard

## Communication Layer

I used Tableau Public to transform evaluation data into three visualizations: Score Distribution, Scores by Category, and Category Comparison. The dashboard helps non-technical stakeholders identify stronger and weaker performance areas without interpreting Python code or statistical tests.

## Design Decisions and Improvements

I included interactive filters for model version, category, and date to support exploration. I excluded technical statistical details to keep the dashboard focused on performance insights.

If I extended the dashboard, I would add summary KPI cards and clearer performance benchmarks. The current results use synthetic data and should not be interpreted as actual model performance.
