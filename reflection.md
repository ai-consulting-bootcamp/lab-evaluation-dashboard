# Reflection

The lab demonstrated the distinction between the analysis layer and the communication layer. Python was used to generate, validate and summarize the evaluation data, while Tableau Public was used to communicate the results through a histogram, category-level box plots and a sorted comparison of average scores. Each visualization addresses a different stakeholder question, and the model, category and date controls provide a way to explore subsets of the data. The dashboard includes the evaluation scope, the meaning of the score scale and a key takeaway highlighting reasoning as the main simulated improvement opportunity. Statistical tests, p-values and confidence intervals were excluded because the dashboard focuses on accessible findings rather than analytical methodology.

One practical lesson was the importance of selecting the correct aggregation: the category comparison initially displayed summed scores as labels alongside bars representing averages. Correcting the labels to use averages ensured consistency with the Python results. In a future iteration, I would use genuine evaluation results with a consistent scoring rubric, comparable test cases and reliable model metadata, add dynamic KPI cards and clearer category labels, and validate all filter interactions systematically. Since the current data is synthetic and model labels are assigned randomly, the results demonstrate the dashboard workflow rather than actual differences in AI model performance.
