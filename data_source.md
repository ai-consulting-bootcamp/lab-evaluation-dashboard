# Data Source

This dashboard uses **Option B: Generated Sample Evaluation Data** from the lab instructions because a consistent dataset was needed to demonstrate model evaluation performance across categories.

The dataset was generated using Python and contains simulated evaluation scores (0–100), five evaluation categories, four model versions, and evaluation dates. The generated data was cleaned and saved as `evaluation_data_clean.csv` for visualization in Tableau Public.

**Note:** The dataset is synthetic and does not represent actual measured model performance.
