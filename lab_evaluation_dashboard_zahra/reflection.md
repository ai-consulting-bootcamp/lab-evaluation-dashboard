# Reflection

I tried to keep the dashboard focused on "what" and "so what", not "how". No p-values, no standard deviations, no mention of the beta distributions behind the data. Instead I used plain sentences ("Scores range from 0 to 100, where 100 is a perfect evaluation") and sorted the Category Comparison chart from strongest to weakest so a stakeholder can see the priority category (`reasoning`, at 40.85) without needing to read numbers carefully. The color gradient on that chart does the same job, weak categories are visibly lighter.
